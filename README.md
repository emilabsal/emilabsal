## Как я работаю

Люблю код, который легко читать, проверять и менять. Для меня хороший frontend - это не только сверстанный экран, но и понятные границы компонентов, предсказуемое состояние, аккуратная работа с API и стабильное поведение во всех состояниях интерфейса.

Обычно обращаю внимание на:

- ясное разделение UI, состояния, бизнес-логики и side effects
- устойчивость интерфейса в loading, empty, error и mobile-сценариях
- переиспользуемые компоненты с простыми контрактами
- производительность, доступность и визуальную аккуратность
- решения, которые помогают команде двигаться быстрее без накопления хаоса
